\section{Supplementary Materials}
\label{sec:suppl}
% 
The supplementary material provided with the CropSense technical paper includes:
% 
\begin{itemize}
\item Extensive ablation study metrics showcasing the effect of varying the mixup probability ratio on hallucination suppression.
\item Additional visual samples of the Out-of-Distribution (OOD) failure cases, specifically focusing on immature green wheat varieties.
\item Detailed hardware utilization graphs (VRAM usage and CUDA core saturation) recorded during the early-stopping phase of the hyperparameter optimization protocol.
\end{itemize}
% 
For full code implementation, hardware setup instructions, and the web dashboard integration, please refer to the main repository documentation.
